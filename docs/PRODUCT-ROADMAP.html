01

North star experience

Quick Folders should preserve momentum from opening the window through finishing a viewing session.

Open. Understand what is available. Pick something in seconds. Resume naturally. Flow into what comes next.

The product wins by removing decisions and repeated setup—not by becoming another traditional media library manager.

<150 ms

Open instantly

Show the last cached view immediately while refreshing in the background.

<5 sec

Choose confidently

Use progress, duration, previews, and smart views to reduce uncertainty.

1 action

Start or resume

Play immediately at the last position without extra navigation or setup.

0 friction

Keep watching

Offer the next useful item through a lightweight, persistent queue.

02

Product principles

The constraints that keep the experience simple as its capability grows.

PRINCIPLE 01

Instant by default

Cached content appears immediately. Indexing, thumbnails, and metadata never block the first useful interaction.

PRINCIPLE 02

Power without clutter

Advanced actions emerge through context, search syntax, shortcuts, and a command palette rather than permanent chrome.

PRINCIPLE 03

Preserve momentum

Playing, triaging, queuing, and marking watched should rarely require a dialog or lose the current position.

PRINCIPLE 04

Stable and calm

No layout jumps, thumbnail flicker, surprise selection changes, or animation that delays meaningful input.

PRINCIPLE 05

Local-first and private

No account, telemetry, or network dependency. Optional online enrichment must be explicit and narrowly permissioned.

PRINCIPLE 06

Opinionated defaults

A useful experience works immediately. Customization exists for genuine workflow differences, not every stylistic detail.

03

Highest-impact product bets

The capabilities most likely to transform a good file browser into a daily viewing companion.

BET 01Highest leverage

Real playback progress and resuming

Replace the binary watched model with a useful viewing state: New, In Progress, and Watched.

  • Resume at the last playback position
  • Show unobtrusive progress and time remaining
  • Automatically mark watched at a configurable threshold
  • Preserve explicit manual overrides
  • Power a prominent Continue Watching view
BET 02Core loop

A lightweight Up Next queue

Make one-click Play Next and Add to Queue persistent across sessions, reorderable, and available from both the browser and IINA menu.

  • Play a folder in order or shuffle unwatched
  • Advance when playback completes
  • Undo accidental queue changes
BET 03Daily speed

Keyboard-first triage

Turn a folder of new files into a rapid inbox: navigate, preview, queue, mark watched, hide, or delete without losing focus.

  • J/K or arrow navigation
  • Space to preview; Enter to play
  • Automatic advance after triage actions
BET 04Discovery

Purposeful smart views

Continue Watching, New, Recently Added, Up Next, Recently Played, and duration-based views answer common questions immediately.

BET 05Visual choice

Complementary list and grid views

Keep the compact list for high-density triage and add a poster grid for visually choosing what to watch.

04

Three-phase roadmap

Sequence the work so each phase strengthens the primary viewing loop before broadening the product.

Phase 1

Perfect the core loop

Create a compelling reason to use Quick Folders every day before adding broader organization features.

  1. Playback progress, resuming, and automatic watched thresholds
  2. Continue Watching as the first smart view
  3. A persistent, lightweight Up Next queue
  4. Keyboard-first triage with stable focus and selection
  5. Recently Added and Unwatched views
  6. Cached startup with explicit performance measurement
Phase 2

Make discovery delightful

Improve visual confidence and surface sophisticated actions without weighing down the primary interface.

  1. List and poster-grid layouts with consistent thumbnail geometry
  2. Progress overlays, calm placeholders, and optional frame previews
  3. A context-aware command palette
  4. Structured search suggestions and saved smart views
  5. Progressively disclosed technical metadata
  6. Context menus and undoable non-destructive actions
Phase 3

Own local episodic viewing

Use filename and folder conventions to make episodic libraries effortless without requiring a media-server setup.

  1. Conservative season and episode recognition
  2. Expandable series groups and natural episode ordering
  3. Next-unwatched episode recommendations
  4. Continue Series and optional queue auto-advance
  5. Duplicate and unplayable-file diagnostics
  6. Optional advanced library-management tools
05

Experience opportunities

A broader idea bank, organized around user outcomes rather than isolated features.

Find

Structured search

Add optional queries such as duration:<20m, is:progress, resolution:4k, and added:this-week, with suggestions and clickable filter chips.

Act

Command palette

Use ⌘K to jump to folders, switch views, change filters, run selection actions, discover shortcuts, and open settings.

Organize

Saved smart collections

Save searches such as “unwatched documentaries under 45 minutes” without moving or duplicating files.

Browse

Fast spatial navigation

Restore folder, selection, scroll, query, and layout; add sibling-folder breadcrumb menus, recent locations, and mouse back/forward support.

Understand

Local media intelligence

Reveal codec, bitrate, frame rate, HDR, audio channels, and subtitle availability only when useful—not as default visual noise.

Recover

Undo and actionable errors

Use undo toasts for reversible actions and errors that offer a direct recovery path, such as locating an unavailable folder.

Preview

Confident visual choice

Use stable aspect-ratio frames, dominant-color placeholders, progress overlays, and optional contact-sheet hover previews.

Integrate

Native file workflows

Add Reveal in Finder, Copy Path, drag-in folder setup, outbound drag, configurable click behavior, and consistent contextual menus.

07

Quality system

Protect the product’s calm, reliable feel with automated checks that mirror real user conditions.

Visual baselines

Screenshot comparisons for light, dark, compact, loading, empty, selection, and modal states.

Keyboard contracts

Regression coverage for focus order, shortcut conflicts, selection anchors, dialogs, and restoration.

Scale benchmarks

Synthetic libraries that detect startup, filtering, scrolling, cache, and memory regressions.

State migrations

Tests for interrupted indexing, older persisted schemas, missing folders, and partially available metadata.

Accessibility

Automated names, roles, contrast, motion preferences, keyboard reachability, and focus visibility.

Diagnostics

A private local debug panel for index state, pending jobs, cache size, and recent recoverable errors.

08

Strategic boundaries

A clear identity makes prioritization easier and prevents sophisticated features from creating a bloated product.

Quick Folders is not trying to become…

  • A server, streaming service, or multi-user media platform.
  • A metadata-heavy replacement for Finder or a full media catalog.
  • An account-driven recommendation engine.
  • A screen dominated by permanent controls for every available action.
  • A tool that forces users to reorganize files before it becomes useful.

Recommended next move

Build the viewing loop before broadening the library.

Treat playback progress as the foundation. It makes Continue Watching, automatic watched state, Up Next, triage, and episodic recommendations materially more useful.

  2. Resume and completion events
  3. Continue Watching view
  4. Persistent Up Next queue
  5. Keyboard triage flow
