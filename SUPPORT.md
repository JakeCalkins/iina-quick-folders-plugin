# Support

For installation and common behavior questions, start with [docs/INSTALLATION.md](docs/INSTALLATION.md) and the in-app `?` keyboard shortcut guide.

- Reproducible Quick Folders bug: use the [bug report form](https://github.com/JakeCalkins/iina-quick-folders-plugin/issues/new?template=bug_report.yml)
- Focused product suggestion: use the [feature request form](https://github.com/JakeCalkins/iina-quick-folders-plugin/issues/new?template=feature_request.yml)
- IINA application question: use [IINA Discussions](https://github.com/iina/iina/discussions)
- Security concern: follow [SECURITY.md](SECURITY.md)

Please do not include private filenames, folder paths, or media metadata in public reports unless they are essential and have been anonymized.
